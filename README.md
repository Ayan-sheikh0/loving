# For Zehnish, With All My Heart ❤

An interactive, responsive love story web experience crafted with love for **Zehnish**.

---

## ✨ Features

- 💖 **Dedicated 8-Page Interactive Story Journey**:
  1. **The Beginning** — Ambient floating glowing hearts, sound toggle & warm opening for Zehnish khan.
  2. **The First Sight** — Dedicated to **11 July (Monday)**, the moment of love at first sight and becoming a devoted one-sided lover.
  3. **Everything About You (Taareefen)** — Interactive cards celebrating her beauty, hair, eyes, smile, cute nose, lips, pure soul, and cute little habits.
  4. **Dil Ki Baat (Love Letter Modal)** — 3D Wax-sealed heart envelope with handwritten parchment letter for Zehnish.
  5. **An Honest Apology & Promise** — Sincere confession & apology for being over-possessive (*"Dil se Sorry"*), with promises of respect, space, and unconditional love.
  6. **Reasons Why My Heart Chose You** — Interactive sparkle truth cards.
  7. **The Question** — Playful interactive proposal with a runaway / dodging "NO" button and exploding confetti celebration on "YES, ALWAYS!".
  8. **The Grand Finale** — Glowing message (*"I LOVE YOU ZEHNISH ❤"*), relationship journey summary, emotional vow, and replay button.
- 🎵 **Romantic Background Music & Audio Synth**: Plays audio with automatic Web Audio API soft romantic chime fallback.
- 📱 **100% Mobile & Laptop Friendly**: Smooth touch-swipe navigation, responsive layouts, and safe-area support.
- 🚀 **Zero-Config Deployment Ready**: Ready for instant deployment to GitHub and Vercel.

---

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev
```

---

## 🌐 Deploy to Vercel (1-Click)

1. Push your repository to **GitHub**:
   ```bash
   git add .
   git commit -m "Zehnish love story ready"
   git push origin main
   ```
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import this GitHub repository.
4. Framework Preset: **Vite** or **Other** (Root directory: `./` or `./shreya-love-story`).
5. Click **Deploy**! ✨
